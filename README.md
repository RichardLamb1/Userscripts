# Userscripts

This repository contains userscripts you can install with a browser userscript manager.

## Install a userscript manager

### Firefox (Greasemonkey)
1. Open Firefox and go to the [Greasemonkey add-on page](https://addons.mozilla.org/firefox/addon/greasemonkey/).
2. Click **Add to Firefox**.
3. Approve the permissions and complete installation.

### Chrome (Tampermonkey)
1. Open Chrome and go to the [Tampermonkey Chrome Web Store page](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo).
2. Click **Add to Chrome**.
3. Confirm by clicking **Add extension**.

## Add a userscript to Greasemonkey or Tampermonkey

1. In this repository, open the script file you want to install.
2. Click **Raw** to open the script source directly in your browser.
3. Your installed extension (Greasemonkey or Tampermonkey) should detect the userscript and show an install prompt.
4. Review the script details and click **Install**.
5. Make sure the script is enabled in the extension dashboard.

## Troubleshooting

- If no install prompt appears, copy the raw script URL and use the extension dashboard option to create/install a script from URL.
- Refresh the target website after installing or enabling a script.
